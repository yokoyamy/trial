# アンケート運営アプリ 実装要件

## 1. 目的

参照モックおよび業務要件に基づき、以下の業務を実際に処理できることを目的とする。

- アンケートの作成・編集・公開・終了
- 顧客の取得・選択
- メール送信・再送
- 回答受付
- 回答状況・回答結果の確認
- メール・kintone設定

モック上だけの表示変更や固定値ではなく、実際に保存されたデータをもとに処理・表示する。

---

## 2. 実装環境・前提

- Apache＋PHPで動作する。
- UTF-8を使用する。
- 画面はindex.phpを中心に実装する。
- テスト段階では運営者認証を実装しない。
- テスト段階ではJSONファイルを保存先とする。
- 将来DBへ移行できるよう、データ間の識別関係を明確にする。

保存先：

```text
data/
├─ settings.json
├─ customers.json
├─ surveys.json
├─ mail_logs.json
└─ responses.json
