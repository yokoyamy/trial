# アンケート業務運営アプリ 実装要件
## 全差し替え版

---

# 1. 基本方針

本アプリは、アンケートの作成、編集、公開、対象者への送信、回答受付、回答状況確認、回答結果集計までを一連の業務として扱う。

本番環境では、モックで確認できる業務フローを維持する。

対象となる主な機能は以下とする。

- アンケート一覧
- アンケート作成
- アンケート編集
- アンケート内容確認
- 顧客一覧
- メール設定
- kintone設定
- 顧客選択
- メール送信確認
- メール送信
- 送信結果
- 回答状況
- 回答結果
- アンケート公開
- アンケート終了

---

# 2. 実行環境

以下の環境で動作すること。

- Apache 2.4
- PHP 8.4 / 8.5
- Windows / Unix
- データベースなし
- cURLを使用しない
- UTF-8
- PHP / HTML / CSS / JavaScriptを1つのindex.phpへ格納

正式なデータ保存先は、アプリルート配下のJSONファイルとする。

---
